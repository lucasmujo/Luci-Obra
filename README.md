# Luci Obra - App de Controle de Gastos

PWA (Progressive Web App) para registrar gastos da obra do estúdio da Luci.

## Funcionalidades

- Registra gastos com data, categoria, valor e fornecedor
- Anexa fotos das notas fiscais
- Grava áudio com informações do gasto
- Funciona offline e sincroniza depois
- Resumo visual dos gastos por categoria

## Como usar

1. Abra no navegador (celular ou desktop)
2. No iPhone: Compartilhar > Adicionar à Tela de Início
3. No Android Chrome: Menu (3 pontos) > Instalar app

## Dados

Os dados ficam salvos localmente no seu celular e nunca saem dele (a menos que você exporte).
